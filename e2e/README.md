# Испытания интерфейса (Playwright)

Гоняются по ВЫКАТКЕ dev — `https://renorma-fit-dev.pages.dev`, — а не по локальной
сборке. Значит проверяемое надо сначала туда выложить (`docs/deploy.md`).

```
npx playwright test                    # весь набор
npx playwright test lazy-food-flag     # один файл
npx playwright test --repeat-each=3    # проверить устойчивость
```

Дополнительных ключей и своих конфигураций не нужно: `playwright.config.ts` сам
подхватывает браузер из образа и прокси, когда они есть.

**Никогда не пропускайте прогон через `| tail`** — через трубу теряется код
возврата, и упавший прогон выглядит зелёным. `npx playwright test > /tmp/run.log
2>&1; echo "код $?"`.

Всё остальное — окружение, `signInSeeded` вместо онбординга, засев базы, разбор
`net::ERR_ABORTED` — в **`docs/testing.md`**, раздел «Второй набор: Playwright
в `e2e/`». Начинать чинить упавшее испытание, не прочитав его, дороже.
